# CYP2D6 external efficacy specialist

## Source audit and what is different

Source snapshot `20260912T101018220424Z-7a70c5e3` preserves the current [SuperCowPowers working notes](https://supercowpowers.github.io/workbench/blogs/cyp_challenge/), `cyp_chemprop_union.py` and `cyp_union_features.py` from the linked [repository](https://github.com/SuperCowPowers/workbench/tree/main/ml_pipelines/OpenADMET/cyp).

The current entry uses external qHTS maximum response as its own auxiliary task, alongside potency and challenge tasks. Our original curation `8792f422` already retained this signal, including inactive observations; this is not newly acquired data. The later external tree pipeline trained potency and hit-classification heads while preserving the unused `max_response` column. Here the new comparison is a dedicated efficacy/dose-response tree specialist whose frozen predictions are added to the CYP2D6 readout.

The upstream `--public-weight 0.30` multiplies each public head's loss relative to the mean primary task weight. Because Chemprop sums losses across observed labels, this does not mean 30% of the total loss mass. The source docstring estimates 72% public,17% challenge-assay auxiliary,11% scored loss mass at0.30, versus30% public at0.05. These are source-specific label-count calculations, not a universal weighting recommendation. The script now builds26heads while the reported entry used18. Our separate frozen tree features have no analogous public-loss weight.

The blog's test-placement adjustment uses leaderboard information; it is not copied into this feature experiment.

## Data and external models

Feature run: `20260912T101212878172Z-616de5d8`.

Input is the original preserved AID1851 raw field table in `8792f422/outputs/pubchem-curated-records.parquet`, using the deposited structures and existing ChEMBL standardization. The run independently checks every accepted connectivity against all6,896 challenge molecules. Assay outcome, maximum response and observed concentration-response values remain distinct labels. No response is converted into a pIC50 label.
