fingerprint Tanimoto kernels: Morgan radius 2, feature Morgan radius 2, atom-pair,
and topological torsion. Sparse fingerprint generation does not use the nominal
4096-bit constructor argument. Two further kernels average all four fingerprints,
then mix that average equally with the frozen external600 cosine kernel.

Each retained outer fold uses the same grouped 20% inner holdout to select C
from 0.3/1/3/10/30 and epsilon from 0.05/0.2 with official ST-RAE. Each chosen
SVR refits all outer-training labels, including anchors. All six methods retain
1,457 canonical OOF predictions, kernel matrices, reference IDs and model assets.
This differs from earlier KNN/local averages and embedding RBF-SVR experiments.

A matched follow-up compares point squared loss with squared distance outside
credible intervals, using RKHS regularization 0.0003/0.003/0.03 selected on inner
ST-RAE. It tests fingerprint-average and fingerprint/embedding-average kernels.
The interval loss is not absolute ST-RAE; the exact metric selects regularization.
