# Scratch PubChem600 encoder and frozen TabPFN readout

The requested 600-dimensional experiment is complete. Standalone macro ST-RAE
is 0.763709, worse than frozen Admetica (0.743910). Adding it to the existing
equal-weight FP/Mordred + predicted-log2fc + Admetica ensemble improves 0.661279
to 0.658841; the neighbor subset improves 0.803584 to 0.787963. Retain it as an
additional ensemble component. This is a single-seed experiment, not evidence
that 600 dimensions or random initialization is intrinsically better.

## Data and training

PubChem AID1851 defines Fit_LogAC50 as log10 AC50 in molar units. We use
`pAC50 = -Fit_LogAC50`, keeping the external assay target distinct from challenge
pIC50. After excluding every challenge connectivity block (including test),
14,245 compounds have 41,699 finite labels across 1A2, 2C19, 2C9, 2D6 and 3A4.
Duplicate SID observations are averaged per standardized compound and endpoint.
Inactive rows without finite potency receive no invented label. This differs
from the earlier external Max_Response experiment and follows the continuous
target idea in Jeremy's downloader, with stricter overlap exclusion.

A randomly initialized Chemprop bond-message encoder uses width 600, depth 5,
mean pooling and a 600-unit regression head with dropout 0.1. Five heads train
jointly with masked, equally weighted headwise MSE and train-only target scaling.
An external 90/10 connectivity-group split selects the checkpoint. AdamW uses
weight decay 1e-4, batch 128, three warmup epochs to 1e-3 followed by cosine decay
toward 1e-4, maximum 80 epochs and patience 12. Seed is 42.

Training stopped after 23 epochs; the best checkpoint is epoch 11 (zero-based 10).
External validation RMSE by head is 0.5703/0.6710/0.6494/0.7048/0.4542.
The encoder then produces 600 frozen features for all 6,896 challenge compounds.
No challenge labels enter external pretraining. The challenge readout is
TabPFN 2.6, eight estimators, on embeddings alone, with no additional descriptors,
log2fc or output-head predictions. Twenty saved fits use the existing five-fold
parent-retained CV. The audit verifies all 6,384 non-anchor OOF keys, labels,
confidence bounds, folds and neighbor flags against the controls.

## Matched results

Scores are macro ST-RAE (lower is better), calculated from pooled OOF per endpoint.
All blends use fixed equal weights, without weight search or calibration.

| Model | All OOF | Neighbors |
|---|---:|---:|
| Original CheMeleon embeddings → TabPFN | 0.721992 | 0.895810 |
| Frozen Admetica embeddings → TabPFN | 0.743910 | 0.819000 |
| PubChem600 embeddings → TabPFN | 0.763709 | 0.876191 |
| FP/Mordred + log2fc | 0.673634 | 0.847109 |
| FP/Mordred + log2fc + Admetica | 0.661279 | 0.803584 |
| FP/Mordred + log2fc + PubChem600 | 0.663721 | 0.805330 |
| FP/Mordred + log2fc + Admetica + PubChem600 | **0.658841** | **0.787963** |

| Endpoint | PubChem600 alone | Previous triple | New four-way mean |
|---|---:|---:|---:|
| 1A2 | 0.808400 | 0.740490 | 0.735039 |
| 2C9 | 0.720566 | 0.554762 | 0.557006 |
| 2D6 | 0.918801 | 0.873043 | 0.866655 |
| 3A4 | 0.607068 | 0.476822 | 0.476664 |

The four-way gain is mostly 1A2 and 2D6; 2C9 worsens slightly. Standalone
PubChem600 improves only 2D6 over frozen Admetica. Architecture, initialization
and training targets all differ, so this is not a controlled capacity comparison.
Weights, keyed predictions, per-fold metrics and prediction/residual correlations
are retained. No submission or current-model pointer was changed.
