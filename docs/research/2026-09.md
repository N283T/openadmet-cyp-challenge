## RL-0005 — CheMeleon-initialized log2fc pretraining

Recorded on 2026-09-10 UTC. Tracks: shared auxiliary representation learning.

**Question.** Adapt the existing CheMeleon encoder to single-concentration log2fc,
following the PXR auxiliary-pretraining approach. Start from CheMeleon weights;
defer scratch initialization and downstream TabPFN experiments.

**Data / preparation.** Run `20260910T100337258849Z-927eac1c` mapped source measurements
to standardized IDs: 4,376 compounds, four complete CYP heads at approximately
49.5 µM, 17,504 labels, no replicated compound/head groups. Use equal-weight,
training-standardized MSE; no FDR filter, sign change or clipping.

**Method / changes from PXR.** Keep CheMeleon's width 2,048, depth 6 and mean pooling,
add BatchNorm and a 256-unit four-head regressor. Train the encoder weights as well
as the new head. Learning rates are 10× lower than the prior scratch recipe; seed 42,
maximum 150 epochs, patience 15. Each outer UMAP holdout is excluded across all
auxiliary heads. A seeded inner 90/10 split is used only for early stopping, not as
an additional CV benchmark. Fit target scalers on inner training only and export
the best inner-validation weights, correcting the old script's pre-split scaling
and final-epoch export. No test or outer labels select the checkpoint.

**Completed runs.**

**Results / audit.** Pooled audit run `20260910T101445700767Z-388556ae` validated

CYP1A2 0.580, CYP2C9 0.709, CYP2D6 0.532, CYP3A4 0.705. Full RMSE/MAE results,

does not establish an optimal learning rate or architecture. No scratch comparison
or downstream pIC50/TDI improvement has been established. The foundation checkpoint
still carries RL-0004's explicit local-weight / unavailable-Zenodo-checksum provenance.

**Next.** Evaluate a fold-matched frozen embedding readout. Predicted log2fc for
TabPFN training rows needs inner cross-fitting within each outer-training set;
joining the global auxiliary OOF table directly can leak that outer holdout through
other encoders. Scratch pretraining remains a later controlled initialization comparison.

## RL-0006 — Embedding-only TabPFN readout

Recorded on 2026-09-10 UTC. Tracks: regression and classification.

**Question / method.** Evaluate the RL-0005 frozen representations first. Use the
encoder corresponding to each held-out UMAP fold, raw 2,048 post-BatchNorm features,
TabPFN-2.6 with eight estimators and seed 42 + fold. Fit separately per endpoint.
No descriptor/FP concatenation, predicted-log2fc inputs, external feature selection,
threshold tuning or TabPFN weight fine-tuning.

**Runs / results.** Five readout runs from `20260910T111808494092Z-67df22cf` through
`20260910T112147200339Z-2bbfe757` are listed in the [full report](../tabpfn-readout.md).

label coverage and official ST-RAE agreement. All runs completed without failures.
Macro ST-RAE 0.731115 and MAE 0.562771 improve over LightGBM + Mordred + Morgan
(0.753365 and 0.580243). Macro MCC falls from 0.165203 to 0.112674, while AUROC
rises from 0.647892 to 0.661075. CYP2D6 TDI predicts all negatives at 0.5
(MCC 0, AUROC 0.566133); CYP3A4 TDI MCC is 0.225348.

**Decision / limitations.** Keep this as the first readout baseline, including
the weak classification result. Save fit states, checkpoint snapshots, OOF and
DB lineage/metrics. This changes both representation and learner relative to the
LightGBM baseline, so does not demonstrate a causal pretraining benefit. No LB
evaluation or submission. No uncertainty estimate from repeated seeds.

**Next.** A foundation-only CheMeleon + identical TabPFN control would isolate
auxiliary adaptation. Any classification threshold selection needs training-side
validation. These follow-ups and scratch initialization are not run in this entry.

## RL-0007 — Foundation PCA and predicted log2fc with TabPFN

Recorded 2026-09-10 UTC. Tracks: regression and classification.

**Question.** Follow the user-supplied official baseline description's feature
recipe, keeping TabPFN instead of TabICL. Preserve foundation CheMeleon features
(PCA 2048 → 256) and append four primary-screen predictions. No Mordred yet.

**Method.** Ten auxiliary models each exclude an unordered pair of UMAP folds.
Training rows use their matching nested out-of-sample predictions; outer validation
rows use the four eligible models' mean. Fit each endpoint/fold PCA on labeled
readout training rows only. Use TabPFN-2.6, eight estimators, seed 42 + fold and
classification threshold 0.5. The [report](../stacked-tabpfn.md) lists all 15 model
runs, checkpoint lineage, feature artifacts and limitations.

**Results.** Audit `20260910T121725442380Z-414b10ed` confirms all 11,606 OOF pairs
and official scoring. Macro ST-RAE 0.729505 (prior embedding TabPFN 0.731115),
MAE 0.563181 (0.562771), MCC 0.124720 (0.112674), AUROC 0.645634 (0.661075).
CYP2D6 TDI remains all-negative at 0.5 with AUROC 0.525112. All runs completed;
models, PCA, features, predictions and DB parent links were saved. No submission.

**Decision / limits.** Keep as a compact baseline, with only marginal metric
changes. Do not infer a substantial gain or attribute effects to predicted log2fc
alone: representation, PCA and auxiliary training construction differ from the
previous experiment. Nested auxiliary fits use fewer training molecules than a
final all-data auxiliary fit. Readout training uses single-model auxiliary values,
while validation uses an average. No repeated-seed uncertainty estimate.

**Next.** Consider adding descriptors or a PCA-only control to identify useful
feature contributions. These are deferred pending the next experimental choice.
